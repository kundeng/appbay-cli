Usage: appbay secrets [options] [command]

Manage secrets — vault CRUD, KeePass CRUD, scanning, and checking

Options:
  -h, --help              display help for command

Commands:
  init [options]          Initialize the local secrets vault
  set <key> [value]       Store a secret in the local vault (supports app/key
                          scoping). Omit VALUE to read it from stdin, which
                          keeps it out of /proc/<pid>/cmdline.
  get <key>               Retrieve a secret from the local vault
  delete <key>            Delete a secret from the local vault
  vault [options]         List all secrets stored in the vault
  init-kdbx [options]     Initialize a KeePass .kdbx database for keepass://
                          secrets
  set-kdbx <key> [value]  Store a secret in the KeePass database (supports
                          app/key scoping). Omit VALUE to read it from stdin,
                          which keeps it out of /proc/<pid>/cmdline.
  get-kdbx <key>          Retrieve a secret from the KeePass database
  delete-kdbx <key>       Delete a secret from the KeePass database
  kdbx [options]          List all secrets stored in the KeePass database
  scan <app>              Discover secret-like env vars in an app's compose and
                          .env files
  import [options] <app>  Scan app and auto-create vault entries for unmanaged
                          secrets
  check                   Check that all secret URI references resolve
  list [app]              List secret references for an app (or all apps)
  help [command]          display help for command
